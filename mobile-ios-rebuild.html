Rebuild Mobile UI hi.undangyah.id — iOS Elegant Style

Goal

Buat ulang dari awal tampilan mobile dashboard hi.undangyah.id dengan iOS Elegant style. Bukan override/patch CSS lama, tapi komponen mobile baru yang terpisah sepenuhnya.

Dua mode UI yang berbeda:

  • Desktop → tetap seperti eksisting (tidak disentuh)
  • Mobile → UI baru dari awal, komponen sendiri, CSS sendiri

Fokus: kesederhanaan, kejelasan, konsistensi, dan keeleganan.

Design System — "Undangyah iOS Elegant"

Filosofi

  • Senada dengan Landing Page — flat, monochrome, editorial/Swiss-grid inspired
  • Clean & Minimal — setiap elemen punya tujuan, tidak ada dekorasi berlebihan
  • Flat colors only — TIDAK ADA gradasi warna di manapun (sama seperti LP)
  • Near-black accent — #0f0f11 sebagai warna utama (sama persis dengan LP)
  • Generous whitespace — ruang napas antar elemen
  • Strong typography hierarchy — ukuran dan weight yang jelas membedakan level informasi
  • Consistent radius — pill untuk button, 12-16px untuk card
  • Mobile-first — desain dimulai dari 320px, scale up ke 480px max

Pendekatan: Rebuild (Bukan Override)

Kenapa Rebuild, Bukan Override?

  • CSS override gagal karena file lama punya specificity tinggi + inline styles di AppLayout.tsx
  • Terlalu banyak !important = unmaintainable
  • Komponen lama terlalu coupled dengan styling One UI

Cara Kerja

  1. AppLayout.tsx detect mobile via useIsMobileLayout()
  2. Jika mobile → render komponen IosMobileApp (wrapper baru)
  3. Jika desktop → render layout eksisting (tidak berubah)
  4. Komponen mobile import data/hooks yang sama, tapi render UI sendiri
  5. Satu file CSS (ios-mobile.css) sebagai design system — semua komponen mobile pakai token ini
  6. File CSS lama TIDAK dihapus — tetap dipakai desktop

Keuntungan

  • Desktop 100% tidak terpengaruh
  • Tidak ada perang specificity
  • Komponen mobile bisa di-iterate tanpa takut break desktop
  • Clean separation of concerns
