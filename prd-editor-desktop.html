PRD: Editor Undangan Desktop

Version 1.0 22 Mei 2026 Platform: Web Desktop Route: /dashboard/edit/:id

1. Overview

Halaman Editor Undangan adalah tempat user mengedit konten undangan digital mereka. Editor menggunakan layout 2-kolom dengan sidebar navigation dan content area untuk form input.

Perbedaan dengan Mobile:
  • Desktop: Sidebar + Content (2 kolom)
  • Mobile: Full screen dengan bottom navigation
  • TIDAK ADA live preview panel di desktop (preview dibuka via tombol di topbar)

2. Entry Point

User bisa masuk ke halaman editor dari:

  • Dashboard Home → Card undangan → tombol "Edit"
  • Dashboard Home → Daftar undangan → klik row
  • URL langsung: /dashboard/edit/:id

7. Flow Lengkap

Step 1: User klik Edit dari Dashboard

Navigate ke /dashboard/edit/:id
Fetch invitation data dari API
Loading state (skeleton)

Step 2: Editor loaded

Tampilkan Welcome view (default)
Sidebar menampilkan semua section
Progress indicator per section

Step 3: User klik section di sidebar

Content area berubah menampilkan form section tersebut
Load field values dari API
Tampilkan form dengan data yang sudah ada

Step 4: User isi/edit form

Input validation real-time
Auto-save setiap 30 detik (background)
Manual save via tombol "Simpan Section"

Step 5: User klik Preview

Buka tab baru dengan URL preview
Render undangan dengan data terbaru

Step 6: User klik Publish

Validasi semua required fields
Jika valid: set status = active, redirect ke Dashboard
Jika invalid: highlight section yang error

8. Responsive Behavior

Breakpoint Layout Behavior
Desktop (≥1024px) Sidebar + Content (2 kolom) Sidebar fixed 220px
Tablet (768-1023px) Sidebar collapsible Hamburger menu, content full
Mobile (<768px) Sidebar sebagai drawer Slide from left, content full
